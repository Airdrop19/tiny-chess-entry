Entry for the make.fun bounty [Build the strongest chess engine in 4 KB of Python](https://make.fun/bounty/tiny-chess-01).

`main.py` (Python 3.13, standard library only, 4,093 bytes) is a 0x88 alpha-beta chess engine with PeSTO tapered evaluation, transposition table, killers, null-move pruning, late-move reductions and quiescence search, searching to a fixed node budget. It plays the house gauntlet through the env at `MAKEFUN_ENV_URL`.
